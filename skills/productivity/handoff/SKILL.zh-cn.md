---
name: handoff
description: 把当前对话压缩成交接文档，供另一个智能体接手。
argument-hint: "下个会话用来做什么？"
disable-model-invocation: true
---

把当前对话压缩成一份交接文档，让全新的智能体能接手继续工作。保存到用户操作系统的临时目录，而不是当前工作区。

文档中包含“建议技能”一节，写明下一个智能体应该调用 Skill 工具加载哪些技能。

不要重复其他产物已记录的内容（规格说明、计划、ADR、issue、提交、diff）。用路径或 URL 引用它们。

脱敏所有敏感信息，如 API 密钥、密码或个人身份信息。

如果用户传了参数，把它视为下个会话重心的描述，并据此裁剪文档。
